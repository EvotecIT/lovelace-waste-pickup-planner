# Waste Schedule Card

Design and implementation plan for a Home Assistant dashboard card that shows what is collected next, with layouts that fit the household's existing dashboard.

**Status:** planning and image-model concepts; no installable card release yet.

The selected name is **Waste Schedule Card**, repository name `lovelace-waste-schedule-card`, with `custom:waste-schedule-card` and an optional `custom:waste-schedule-badge`. The name describes the job and does not tie the frontend to a municipality or one integration fork.

- [Design and API plan](docs/design-and-api.md)
- [Hero concept](docs/design/hero-concept.png)
- [Compact, schedule, badge, and theme concepts](docs/design/layouts-concept.png)

The concepts use example dates and explicitly supplied example colors. They illustrate the direction; spacing, contrast, responsive behavior, and interactions still need verification in Home Assistant.
